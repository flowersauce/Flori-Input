# 坐标选取器手动验收

这些步骤不由 CMake 自动执行。请在可安全点击的桌面环境中进行，不要在游戏或有未保存内容的窗口上测试。

1. 进入触发器页开始坐标选取：鼠标旁应只显示小型坐标信息框，屏幕不再整体变暗；指针显示为十字形。
2. 将鼠标高速移过按钮、输入框和不同屏幕：下方控件不应出现悬停或点击反馈；同一悬浮窗口应贴着指针移动，不能产生明显追赶现象。单击左键后应保存按下瞬间的坐标，且下方窗口不应收到点击。
3. 在每块显示器的四边与四角停留：信息默认在指针左上方，接近边界时应转到另一侧；信息卡片不能伸入相邻显示器之间的空白区域。左侧或上方副屏应显示负坐标；混合缩放比例下也应检查。
4. 右键与 Esc 都应取消选取；左、右键按下与抬起不能透传到下方窗口。退出选取后，下方窗口应恢复正常交互。
5. 选取期间改变显示器排列或断开副屏：悬浮窗口应跟随鼠标切换显示器，信息仍在鼠标所在屏幕内；关闭软件后不应留下窗口。

坐标信息和透明防交互区域共用一个小型 Slint 窗口，不再创建逐显示器的全屏窗口。建议在 4K/多屏环境观察窗口跟随、显存、CPU 和边缘避障效果。
