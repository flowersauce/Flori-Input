# 用户场景体验脚本

三个可体验的完整场景，合计覆盖当前全部 7 个命令。它们是手动体验脚本，不会自动执行。

## 使用方法

1. 在软件的事件剧本页点击“打开剧本目录”，将本目录的三个 `.fsevent` 文件复制到该目录第一层。
2. 点击“刷新”并选择脚本；画图场景需先修改坐标、保存并刷新。
3. 保持软件停留在事件剧本页，切换到目标应用并点击空白文档或画布，再按启动热键（默认 `F8`）。
4. 再次按启动热键可提前停止。第三个场景包含无限循环，需要主动停止。

请使用新建的空白文档和画布；脚本会实际输入文字、点击和滚动。

## 场景与预期结果

| 脚本                                         | 准备                                               | 预期结果                                                                                                               | 覆盖命令                                    |
|----------------------------------------------|----------------------------------------------------|------------------------------------------------------------------------------------------------------------------------|---------------------------------------------|
| [多语言测试卡](01_multilingual_card.fsevent) | 空白记事本                                         | 输入中英文、emoji、双引号及字面量 `\n`；生成三行 `[完成]` 加 Tab 和 `★★★`；最后光标先到开头、再回到末尾，自动结束。 | `text`、`stroke`、`wait`、`repeat`          |
| [鼠标绘制方框](02_draw_square.fsevent)       | 画图中新建空白画布，选铅笔工具并调整坐标           | 按住左键沿四角绘制闭合方框，释放后在框内点一下，自动结束。                                                             | `move`、`event`、`wait`、`stroke`           |
| [长文档循环滚动](03_scroll_loop.fsevent)     | 空白记事本，窗口高度不超过约 20 行，鼠标放在正文区 | 生成标题、60 行正文和结尾，回到开头；反复向下滚动、暂停、向上滚动、暂停，按 F8 停止。                                  | `text`、`stroke`、`wait`、`wheel`、`repeat` |

第一和第三个场景覆盖嵌套有限循环；第三个同时覆盖无限循环和滚轮正负方向。
字体可能影响 emoji 和星号的显示；Tab 宽度与每步滚轮距离取决于编辑器和系统设置。

## 画图坐标如何调整

使用事件剧本页的“捕获坐标”，分别记录画布内方框的左上、右上、右下、左下和中心点。
替换脚本中全部六处 `move`，其中第一处与第五处使用同一个左上角坐标。
坐标是屏幕物理像素；不要使用画图状态栏显示的画布坐标。调整后保持画图窗口的位置和大小不变。
建议边长约 200 像素，所有点均落在画布内，远离工具栏。

完整语法见[事件剧本手册](../../docs/features/event-script.md)。
