# Font Licenses

Flori Input bundles a `FloriInputUI` font combining Jura's Latin glyphs with Sarasa UI SC's Chinese glyphs for a
consistent interface. This is a derivative font, not an original release from either font project.

## FloriInputUI

The corresponding file is `FloriInputUI-Medium.ttf`. Its source fonts and licenses are described below.

## Jura

[Jura](https://github.com/ossobuffo/jura) carries the copyright notice “Copyright 2019 The Jura Project Authors”.
See [Jura's OFL file](https://github.com/google/fonts/blob/main/ofl/jura/OFL.txt) for the original notice and the full
SIL Open Font License 1.1 text.

## Sarasa UI SC

[Sarasa UI SC](https://github.com/be5invis/Sarasa-Gothic) belongs to the Sarasa Gothic font family. Its copyright
notices also cover some glyphs from Inter, Adobe, and Google. Refer to
the [Sarasa Gothic license](https://github.com/be5invis/Sarasa-Gothic/blob/main/LICENSE) for the original wording.

## Terms of use

Both source fonts use the [SIL Open Font License 1.1](https://openfontlicense.org/open-font-license-official-text/). It
permits embedding and distributing modified fonts while requiring the relevant copyright notices and license to be
retained. The source-project links above provide the original notices and full texts.
See [Third-party Components](third-party.en.md) for the other bundled components.
