# Responsible Use and Authorization

Flori Input is a local keyboard and mouse input tool. Before using it, make sure you are authorized to operate the
target device, account, and application, and follow applicable laws and the rules of the target app or service.

Do not use this tool for unauthorized operations, harassment or spam, bypassing access controls, or infringing others'
rights. The project does not provide guidance or custom support for such uses.

Automated input affects the current target window. Before starting, check the target, input content, and stop hotkey,
and test scripts or repeated input in a safe window first.
