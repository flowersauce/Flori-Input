# 字体许可

Flori Input 内置的 `FloriInputUI` 字体组合了 Jura 的西文字形与 Sarasa UI SC 的中文字形，让中英文界面保持一致。它是派生字体，不是这两个项目提供的原版字体。

## FloriInputUI

对应的字体文件为 `FloriInputUI-Medium.ttf`。字体来源和许可信息如下。

## Jura

[Jura](https://github.com/ossobuffo/jura) 的版权声明为“Copyright 2019 The Jura Project Authors”。原始声明及完整 SIL Open
Font License 1.1 文本见 [Jura 的 OFL 文件](https://github.com/google/fonts/blob/main/ofl/jura/OFL.txt)。

## Sarasa UI SC

[Sarasa UI SC](https://github.com/be5invis/Sarasa-Gothic) 属于 Sarasa Gothic 字体系列。其版权声明还涵盖 Inter、Adobe 和
Google 的部分字形；请以 [Sarasa Gothic 的许可证原文](https://github.com/be5invis/Sarasa-Gothic/blob/main/LICENSE)为准。

## 使用条件

两款来源字体均采用 [SIL Open Font License 1.1](https://openfontlicense.org/open-font-license-official-text/)
。该许可允许在软件中嵌入和分发修改后的字体，同时要求保留相应版权声明及许可证；上面的源项目页面提供原始声明和全文。其他第三方组件见[第三方组件](third-party.md)。
