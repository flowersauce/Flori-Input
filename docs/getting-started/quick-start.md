# 快速开始

Flori Input 的三项输入功能分别位于“触发器”“模拟粘贴”“事件剧本”页。它们默认都使用 `F8` 作为启动热键，但
**只响应当前功能页**；运行中切换页面会先停止当前任务。

## 试一次鼠标连击

1. 打开“触发器”，保持默认的左键、连击和自由光标设置。
2. 将鼠标移到可安全点击的位置，按 `F8` 开始，再按 `F8` 停止。
3. 需要修改速度时，调整输入周期和按压时间；两者的界面单位都是秒。

## 试一次模拟粘贴

1. 打开“模拟粘贴”，输入一段短文本，或保持文本框为空以使用最新剪贴板文本。
2. 在记事本里点选输入位置，按 `F8`；文字输入完毕后任务会自行结束。

## 试一个事件剧本

1. 打开“事件剧本”，点击“打开剧本目录”，新建 `hello.fsevent`。
2. 用文本编辑器保存下面的 UTF-8 内容：

   ```text
   text("你好，Flori Input", 5, 20);
   stroke(Key.Enter, 5);
   ```

3. 回到软件，点击“刷新”并选择文件。切到记事本的输入位置后按 `F8`。完整语法见[事件剧本](../features/event-script.md)。

如果状态栏显示错误，先检查输入目标、热键和剧本文件。不要在有未保存内容或可能触发危险操作的窗口中直接尝试自动化。
