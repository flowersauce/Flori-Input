# Flori Input 用户手册

Flori Input 是一款面向 Windows 的键鼠输入工具，支持重复输入、模拟粘贴和事件剧本。

## 入门

- [安装与更新](getting-started/installation.md)：选择安装版或便携版，了解配置保存位置。
- [快速开始](getting-started/quick-start.md)：用三个小例子体验主要功能。

## 功能

- [触发器](features/trigger.md)：鼠标或键盘连击、长按、固定坐标输入。
- [模拟粘贴](features/paste.md)：把文本逐字发送到目标输入框，留空时可使用剪贴板文本。
- [事件剧本](features/event-script.md)：组合文字、按键、鼠标、等待和循环操作；附完整命令说明。

## 设置
