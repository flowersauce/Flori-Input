# Language and Appearance

Change the interface language, theme, and app scale on the **Set** page. Your choices are saved and remain in effect
after restarting.

## Interface language

- **Auto**: Uses Simplified Chinese or English according to the preferred Windows display language.
- **简体中文**: Uses the Chinese interface.
- **English**: Uses the English interface.

The interface language does not change event-script command names; commands are always written in English.

## Theme

- **Auto**: Follows the Windows app theme.
- **Dark**: Uses the dark theme.
- **Light**: Uses the light theme.

## Scale

Choose `100%`, `125%`, or `150%` to adjust the Flori Input interface size.
