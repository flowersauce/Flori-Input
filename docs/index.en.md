# Flori Input User Manual

Flori Input is a Windows keyboard and mouse input tool for repeated input, simulated paste, and event scripts.

## Getting started

- [Install and update](getting-started/installation.en.md): Choose an installer or portable package and find your
  configuration files.
- [Quick start](getting-started/quick-start.en.md): Try the three main features with short examples.

## Features

- [Trigger](features/trigger.en.md): Repeat or hold mouse buttons and keyboard keys, including input at a fixed
  position.
- [Simulated paste](features/paste.en.md): Type text into a target field one character at a time, or use clipboard text
  when the field is empty.
- [Event scripts](features/event-script.en.md): Combine text, keys, mouse input, waits, and loops; includes a complete
  command reference.

## Settings

- [Language and appearance](settings/language-and-appearance.en.md): Change the interface language, theme, and scale.
