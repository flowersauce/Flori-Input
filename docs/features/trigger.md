# 触发器

触发器适合重复点击、重复按键，或临时按住某个键。选择好输入后，切到目标窗口，按启动热键即可开始；再次按同一热键停止。默认热键为
`F8`，只有停留在“触发器”页面时生效。

## 设置输入

- **输入按键**：可选鼠标左键、中键、右键，也可以点击“捕获”指定键盘按键或滚轮方向。自定义输入键不能与本页启动热键相同。
- **输入行为**：“连击”会反复执行按下、抬起；“长按”会保持按下，直到停止。滚轮只支持连击。
- **光标移动**：“自由”在当前指针位置执行鼠标操作；“固定”在指定坐标执行。使用坐标捕获时，移动指针到目标位置后左键确认，右键或
  `Esc` 取消。坐标支持多显示器，左侧或上方屏幕可能出现负数。

## 连击时序

界面中的时间单位是 **秒**，支持三位小数，例如 `0.010` 为 10 毫秒。

- **输入周期**：两次输入开始之间的目标间隔，默认 `0.010` 秒。
- **按压时间**：每次保持按下的时间，默认 `0.005` 秒；`0.000` 表示立即提交按下与抬起。长按和滚轮不使用此项。
- **动态误差**：在目标周期附近加入随机变化，范围 `0%`～`50%`，默认 `0%`。

为了留出抬起时间，按压时间大于零时，最小周期为“按压时间 + `0.001` 秒”；按压时间为零时，最小周期为 `0.001` 秒。实际速度还会受到
Windows 调度、目标软件和电脑负载影响，设置值不保证精确 CPS。

## 停止与状态

运行中再次按启动热键可停止，页面底部状态栏会显示运行或错误状态。停止时软件会尝试释放已按住的按键。建议先在不会造成误操作的窗口里确认热键和输入效果，再用于游戏或其他应用。
