# 模拟粘贴

有些输入框不允许普通粘贴。模拟粘贴会把文字逐字符发送到当前目标窗口，适合在这些输入框中输入短文本；它不是剪贴板粘贴，也不能保证所有软件或受保护输入框都接受模拟输入。

## 使用方法

1. 停留在“模拟粘贴”页，在文本框中输入要发送的内容；如果留空，启动时会读取剪贴板里的最新文本。
2. 选择输入策略，并按需要调整按压时间和输入间隔。
3. 切到目标输入框，按启动热键（默认 `F8`）。任务完成后会自动停止；运行期间再次按热键可以提前停止。

启动热键可在本页单独修改，也可以与触发器或事件剧本使用相同键位；热键只对当前功能页生效。页面底部状态栏会显示运行结果或错误。

## 输入策略

- **模拟按键**：优先发送可由键盘表达的按键；无法映射的字符会回退为 Unicode 输入。更适合依赖键盘事件的目标程序。
- **Unicode 字符**：对每个字符直接发送 Unicode 输入，适合中文及其他非 ASCII 文本；部分游戏或特殊控件可能不接收。

可以先用记事本验证输出，再在目标应用里尝试。如果目标忽略某一种策略，切换另一种试试。

## 输入时间

界面中的时间单位是 **秒**，支持三位小数。按压时间默认 `0.005` 秒，表示每个字符按下到抬起的时长；输入间隔默认 `0.010`
秒，只发生在相邻字符之间，文本开始和结束时不额外等待。两项均可设为 `0.000`。

例如输入 `ABC` 且间隔为 `0.100` 秒，只会在 A/B 和 B/C 之间各等待一次，不会在 C 后再等待。
